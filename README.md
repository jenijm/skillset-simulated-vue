# Simulated Vue.js Assessment: Expense Tracker

## Task brief

Build a Vue.js expense tracker that allows a user to record and review everyday spending.

### Requirements

- Add an expense with a description, amount, category, and date.
- Validate required fields and ensure the amount is greater than zero.
- Display expenses in date order.
- Filter expenses by category.
- Calculate total spending, filtered spending, and the highest expense.
- Delete an expense after confirmation.
- Retain expense data after a browser refresh.
- Provide a responsive interface for desktop and mobile.

## Implementation

The completed application uses Vue 3 Composition API, computed properties, reactive state, and browser `localStorage`. No backend is required.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

Open the URL displayed in the terminal, normally `http://localhost:5173`.

## Create a production build

```bash
npm run build
```

## Preview the production build

```bash
npm run preview
```
